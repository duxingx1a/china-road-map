# v1.0.4 稳定版记录

归档日期：2026-10-13（Asia/Shanghai）。该版本经使用者确认，作为后续维护的起点。

## 当前状态

- 网站：<https://ydl66.top/map/>。
- 后端：Rust 1.0.4，静态 musl 程序，本机 Ubuntu-22.04 WSL 构建。
- 镜像：`china-road-map:1.0.4`，数据目录独立只读挂载，服务器不编译代码。
- 容器：`china-road-map`，由已有 Nginx 代理至 `/map/`，不额外公开应用端口。
- 本机：`python server.py --open`，默认监听 `127.0.0.1:8766`。
- 部署与验证记录：`deployment.json`、`verification-*.json` 和 `deploy/README.md`。

## 已确定的产品行为

中国范围的离线矢量底图，境外为浅灰遮罩。国道红色、高速绿色，国家与省级高速标签分别带红色和黄色顶栏。省界与地名不随未选道路淡化。

最多十条路线同屏比较，点击已选道路可取消。普通选择保持中心和比例尺，仅概览按钮调整视野；恢复按钮返回第一次概览前的视野。最粗比例尺为 300 公里。道路名称为主标题，类别和起终点为次标题，没有起终点资料的省级高速显示省份。

手机使用底部抽屉，默认只露出搜索框；把手上拉或聚焦搜索展开内容区，下拉或返回按钮收起。选路返回地图，详情为紧凑底栏，六个地图操作横向排列。桌面使用独立侧栏。

## 数据与性能决策

原始数据保留本地，展示路线使用三个精度层级，分别为 200m、10m、0.4m 简化阈值，不跨缺口拼接。底图 z<=11 使用精简副本，近景使用原始 MBTiles；请求、缓存与 gzip 均限制资源占用。

数据快照基于 2026-10-11 的 OSM 提取和2022年国家目录，1,579 个编号、1,377 个有展示走向。原始标签、隔离路段和复核依据保留本地。补数据应核对编号、关系、地区及连通性，不能仅根据编号文本或孤立线段直接合并。

公开服务关闭原始数据下载，使用视野范围约束与 Nginx 限流。没有登录要求，也没有声称前端加密能防止公开绘图数据被复制。

## 验证范围

当前前端自动检查 11 项、Rust 单元测试 6 项通过，服务器公开模式功能检查通过。几何精度、Python/Rust 数据一致性及限流行为有独立记录，各记录按其执行时点理解，不把历史检查视为每个版本都重新执行。

手机尺寸检查包括 320×568、390×844、844×390，覆盖上拉/下拉、搜索、选路返回、横向溢出与紧凑详情。桌面检查包括 1280 像素宽。键盘与安全边距适配仍需真实手机持续验证。

## 本地恢复

本地归档包含 Git 历史 bundle、源码 zip、完整 data 目录备份、当前 Docker 镜像、校验清单，以及本项目的实际部署配置。归档保存于项目目录之外，数据和镜像不上传 GitHub。

1. 使用 `git clone source.bundle map` 恢复源码及版本历史，或解压源码 zip。
2. 解压数据包至项目根目录，恢复 `data/`。
3. 本机运行 Python 服务；服务器通过 `docker load` 导入归档镜像，再按 Compose 与 Nginx 文档启动。
4. 检查归档 SHA256、数据库及服务健康状态后，再继续修改。

此次归档保留继续维护能力，不停止线上服务，也不将 GitHub 仓库设为只读归档。
